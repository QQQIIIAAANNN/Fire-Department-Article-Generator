## 🛠️ 主要功能與操作流程

1. **API 金鑰填寫**:
   - 在網頁右上方（電腦端）或頂部（手機端）輸入您的 **Gemini API Key**。
   - 金鑰會以加密方式儲存於您本機瀏覽器的 `localStorage` 中，**安全不外洩**，且下次開啟時會自動填入，不需重複輸入！
   - 普通文字生成使用 Google 最新輕量高速模型：`gemini-2.5-flash-lite`。

2. **基本資訊輸入**:
   - **發文日期**: 預設為當日，Word 匯出時會自動轉換為標準公文民國年格式（如：`中華民國 115 年 6 月 1 日`）。
   - **宣導/訓練地點**: 輸入本次活動的地點（例如：`公館國中`、`駐地`、`館東活動中心`）。
   - **發稿單位、聯絡人、電話**: 已為您預設好公館分隊的官方資訊，您也可以自由微調。

3. **文章設定**:
   - **語氣**: 支援 **專業嚴謹**（強調標準作業程序）、**親切活潑**（貼近大眾）、**熱血宣傳**（凸顯同仁訓練辛勞與英勇）三種不同語氣。
   - **字數**: 可選擇 300字、500字 或 800字 的長度。

4. **主題與大綱輕鬆複選 (主題矩陣)**:
   - **體技能訓練**: 救生氣墊操作、救護技術測驗（燒燙傷處置等）、空氣呼吸器消耗訓練、新式體能測驗。
   - **消防宣導**: 住宅用火災警報器設置與維護、夏日防溺安全原則、火災逃生應變觀念、用火用電安全、防震防颱準備。
   - **大綱展開**: 勾選任何一個項目，下方會**自動滑動展開**該項目的細部要領大綱（如：氣墊的抱胸躺跳姿、住警器的定期按壓測試等），您可以複選要納入 AI 生成提示詞的大綱要點。

5. **上傳現場真實照片 (最多 4 張)**:
   - 支援拖曳或點選上傳當天拍攝的真實照片。
   - 上傳後，系統會**自動對照片進行 Canvas 壓縮**（限制最長邊為 800px），這能大幅加快生成與匯出速度，防止產生容量過大而打不開的 Word 檔。
   - **AI 照片說明**: 生成文章時，Gemini 會根據您寫的新聞稿內容，**自動為每一張照片生成合適的專業照片說明**！您也可以在「Word 預覽模式」下，直接點擊說明文字進行手動修改。

6. **即時雙模預覽與導出**:
   - **Facebook 貼文預覽**: 實時以 Facebook 貼文排版模擬展示（包含照片拼貼網格），滿意後點擊下方「複製文章內文」即可一鍵複製。
   - **Word 公文下載預覽**: 完美模擬官方新聞稿（發文範本.doc）的排版，呈現精美紅線標題與 metadata 格線表格。
   - **一鍵下載 Word 檔 (.doc)**: 點擊按鈕，系統會產生一個完美排版的 Word 檔，且**會自動把您上傳的照片以 Base64 編碼嵌入在 Word 檔案中**！當您使用 Microsoft Word 開啟時，會看到排版整齊、照片與照片說明都自動填寫完畢的精美文件，完全不需再次手動插入照片與調整版面！

## 💡 常見問題

- **為什麼點擊「一鍵生成」後沒有反應？**
  請確認您的 Gemini API Key 是否輸入正確、當前網路連線是否正常，且是否有勾選至少一項主題與大綱。
- **生成的照片說明可以修改嗎？**
  可以！在右側切換至「Word 公文下載預覽」分頁，每張照片下方都有一個文字輸入框，您可以直接打字修改，下載的 Word 檔案將會採用您修改後的照片說明！
